# Logo options

Vector redraws of the three mascot finalists, kept here until one is chosen. None is
used by the site yet; the live logo is still `src/assets/em.svg`.

| File | What it is |
|---|---|
| `c1-owl.svg` | Owl. The right eye's catchlight uses the season colour (`--color-accent`). |
| `p1-penguin.svg` | Penguin in graphite and bone, on a clear background. |
| `p3-penguin.svg` | Classic penguin on its own ink-blue square. |

The generated source images (all twelve candidates) are in the Figma file
"Mikey Nguyen portfolio - logo options":
https://www.figma.com/design/jgHaeY4uK6p0Ck380hi6uv

To use one: copy it over `src/assets/em.svg`.
